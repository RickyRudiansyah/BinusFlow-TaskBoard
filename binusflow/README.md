# BinusFlow

Website to-do list buat track progress tugas. Final Project Web Programming.

## Cara Run

```bash
npm install
npm run dev
```

Buka http://localhost:5173

## Fitur

- Dashboard dengan 3 kolom (To Do, In Progress, Done)
- Drag & drop task antar kolom
- Search task realtime
- Custom warna task
- Configuration page buat manage warna

## Tech Stack

- React + TypeScript + Vite
- @dnd-kit (drag drop)
- React Router
- Lucide Icons
- LocalStorage buat simpan data
